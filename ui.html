Validate fields

Label, hint and error are wired to the control (for, aria-describedby, aria-invalid, aria-required). Editing a field clears its error. validate() returns a boolean.

04 / Toast
Success toast Error toast Info toast Sticky (no auto-dismiss) Dismiss all

Stacks bottom-right (full-width on mobile). Auto-dismiss pauses on hover and keyboard focus. Announced through a shared live region — success/info polite, error assertive. Prefer this over alert() in new code paths.

APISignatureNotes
Toast.show({ title?, message, variant?, duration? }) → { dismiss }duration 0 = sticky
Toast.success/error/info(message, opts?)Sugar over show()
Toast.dismissAll()Clears the stack
05 / Disclosure
A signed shipper declaration, UN number and class, emergency contact, and a tremcard. We prepare the corridor-specific permit pack. Typical clearance is 4–12 hours with pre-lodged documents. After-hours dispatch means we stage the convoy to hit the post at first light. Yes — full GIT cover is available on every corridor, with A-rated underwriters and declared-value options for high-risk cargo.

WAI-ARIA accordion pattern: trigger is a real <button> with aria-expanded + aria-controls; panel is a labelled region. Keyboard: Tab + Enter / Space.
